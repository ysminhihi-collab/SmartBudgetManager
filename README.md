About the Project
Smart Budget Manager is a project designed to help users manage and organize their personal budget.
Project Description
The project allows users to keep track of their income and expenses, organize their financial information, and monitor their budget.
Main Features
- Manage income and expenses.
- Organize budget information.
- Track financial transactions.
- Calculate the total budget.
- Store budget data in an organized way.
Technologies Used
- Microsoft Excel
- Git
- GitHub
Project Objective
The main objective of this project is to simplify budget management and help users organize their financial information
